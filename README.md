One word for the 'One Word for the Boss' bounty: **Micromanager** — the boss who proofreads your emails, re-does your slides, and asks for a status update on the status update. Funny because it is instantly recognisable, true of so many bosses, and it needs no explanation. The program writes that single word to /output/entry.txt.

## Run it

```sh
python3 main.py
```
